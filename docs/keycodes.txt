====================================
 Guncon3Windows - Keycode Reference
====================================

This file lists all supported keycodes recognized by Guncon3Console.exe
when used for input mapping (in mapping.txt).

Usage example in mapping.txt:
  KEYBOARD.30 = C1
  MOUSE.Left  = Trigger

You can also run the program manually with:
  Guncon3Console.exe keys
to print this same list on screen.
